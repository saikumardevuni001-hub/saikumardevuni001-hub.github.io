# Sai Kumar Devuni — Personal Portfolio

A responsive, dark professional portfolio built with plain HTML, CSS and JavaScript. No frameworks, build tools, paid hosting, or external assets are required.

## Preview locally
1. Extract the ZIP.
2. Open `index.html` in a browser.

## Publish free with GitHub Pages
1. Create/sign in to a GitHub account at https://github.com.
2. Create a new **public** repository named exactly `YOUR-GITHUB-USERNAME.github.io`.
3. Upload `index.html` and the complete `assets` folder (including `sai-kumar-devuni.jpg`) to the repository root, then commit the changes.
4. Open **Settings → Pages**. If prompted, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
5. Wait for deployment. Your site will be at `https://YOUR-GITHUB-USERNAME.github.io`.

GitHub's interface can change slightly; the repository name and Pages settings are the key parts. Free GitHub Pages hosting is suitable for a static portfolio.

## Before publishing — please verify and personalise
- Confirm all employment dates and titles.
- Confirm every listed tool reflects your actual hands-on knowledge.
- Add the six Spinnaker Analytics project names and accurate summaries in the Projects section.
- Add a PDF resume link if you want visitors to download your CV. Put the PDF in the repository and link it from the page.
- Consider using a dedicated professional email and review what personal information you want public.
- Never publish passwords, client confidential data, internal IP addresses, private logs, or employer-owned screenshots.

## Edit
Open `index.html` in VS Code or any text editor. Search for the text you want to change. All styling and page content are in this one file.
